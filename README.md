## 📌 Sobre o projeto

Este projeto foi desenvolvido em **HTML** com o objetivo de criar uma página web inspirada na série **O Mentalista (The Mentalist)**.

A página apresenta informações sobre a série, seus personagens e outros conteúdos relacionados, utilizando os conhecimentos adquiridos durante as aulas de Desenvolvimento de Sistemas.

## 🎥 Sobre a série

**O Mentalista (The Mentalist)** é uma série policial e de investigação que acompanha **Patrick Jane**, um consultor com grande capacidade de observação e leitura do comportamento humano.

Patrick utiliza suas habilidades para ajudar a solucionar crimes enquanto busca descobrir quem é responsável por acontecimentos importantes de seu passado.

A série combina investigação, suspense, drama e mistério, apresentando diferentes casos ao longo dos episódios.

## 💻 Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Localize o arquivo `index.html`.
4. Abra o arquivo em um navegador, como Google Chrome, Microsoft Edge ou Firefox.

### GitHub Pages

Caso o **GitHub Pages** esteja configurado no repositório, o projeto também poderá ser acessado diretamente pelo navegador por meio de uma página publicada.
